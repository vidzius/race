NEON SCRAMBLE — ITCH.IO QUICK SETUP

1. Upload this full project to a GitHub repository.
2. In Render choose New > Blueprint and select that repository.
3. Wait for Render to give you an https://...onrender.com URL.
4. Double-click prepare_itch_build.bat and paste that Render URL.
5. Upload the generated Neon-Scramble-Itch.zip to itch.io.
6. itch.io project kind: HTML Game.
7. Recommended display: Click to launch in fullscreen.
8. Enable Mobile Friendly and the fullscreen button.
9. If using an embedded frame instead, use 1280 x 720.

Do not upload server.py as the itch.io playable file. itch.io hosts only the
four-file browser client; Render runs the Python multiplayer server.

Free Render servers can need roughly one minute to wake after being idle.
